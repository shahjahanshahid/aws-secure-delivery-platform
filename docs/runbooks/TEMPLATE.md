# Runbook: Short problem description

- **Applies to:** host, cluster or service
- **Last tested:** YYYY-MM-DD (link to evidence)

## Symptoms

What an operator sees: alert name, error message, failing check.

## Safe diagnostics

Read-only commands first. Show the command and what a healthy result looks
like.

```bash
# command
```

## Interpretation

What each likely result means and which fix applies.

## Remediation

Steps to fix, smallest change first. Mark any step that is destructive or
needs approval.

## Verification

The command or check that proves it is fixed, with the expected output.

## Rollback

How to undo the remediation if it makes things worse.

## Related

Linked incidents, ADRs, alerts and dashboards.
